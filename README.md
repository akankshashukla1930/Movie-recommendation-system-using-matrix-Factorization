# 🎬 Movie Recommendation System Using Matrix Factorization

An end-to-end, production-grade personalized Movie Recommendation System built from scratch using **Collaborative Filtering**, **Low-Rank Matrix Factorization**, and **Stochastic Gradient Descent (SGD)** in Python and NumPy. Complete with exploratory data analysis, evaluation diagnostics, unit tests, and an interactive Streamlit web application.

---

## 📌 Business Problem

In today's digital streaming ecosystems (Netflix, Prime Video, Hulu), users face severe choice paralysis across thousands of catalog titles. Without tailored discovery, engagement drops and subscriber churn escalates. 

Content filtering based on genre alone fails to capture nuanced personal taste and subtle film attributes. Collaborative filtering solves this by uncovering hidden user preference patterns and latent item characteristics from historical user ratings.

---

## 🎯 Project Objective

1. Design and train a **Matrix Factorization** recommender model **from scratch** using NumPy and SGD.
2. Incorporate a global mean baseline ($\mu$), user biases ($b_u$), movie biases ($b_i$), and $k$-dimensional latent factors ($P_u, Q_i$).
3. Eliminate duplicate user-movie interactions and manage ultra-sparse (98.30% empty) rating matrices.
4. Strictly filter out movies a user has already rated to recommend genuine **unseen** titles.
5. Provide a responsive, interactive **Streamlit web application** for real-time recommendation inference.

---

## 📊 Dataset

The system is trained and benchmarked on the official **MovieLens** dataset:
- **Total Interactions:** 100,836 ratings
- **User Base:** 610 unique verified reviewers
- **Movie Catalog:** 9,742 unique titles with genre metadata
- **Rating Scale:** 0.5 to 5.0 stars (0.5 star increments)
- **Mean Rating:** 3.50 ($\pm 1.04$ standard deviation)
- **Matrix Sparsity:** 98.30%

The pipeline automatically inspects file formats and detects column schemas dynamically (accommodating `ratings.csv`/`movies.csv` or MovieLens 100K `u.data`/`u.item`).

## 🧮 Matrix Factorization & Mathematical Formulation

Matrix Factorization decomposes the observed sparse rating matrix $R \in \mathbb{R}^{|U| \times |I|}$ into user latent factor matrix $P \in \mathbb{R}^{|U| \times k}$ and movie latent factor matrix $Q \in \mathbb{R}^{|I| \times k}$, augmented by global and individual bias terms.

### 📐 Rating Prediction Formula

$$\hat{r}_{u,i} = \mu + b_u + b_i + P_u \cdot Q_i^T$$

Where:
- $\mu$: Global average rating across the training dataset ($\approx 3.50$).
- $b_u$: User bias capturing individual rating leniency or strictness.
- $b_i$: Movie bias capturing general catalog popularity or universal critical acclaim.
- $P_u \in \mathbb{R}^k$: $k$-dimensional latent interest vector of user $u$.
- $Q_i \in \mathbb{R}^k$: $k$-dimensional latent attribute vector of movie $i$.

### 🎯 Loss Function with $L_2$ Regularization

$$\mathcal{L} = \sum_{(u, i) \in \mathcal{K}} \left(r_{u,i} - \hat{r}_{u,i}\right)^2 + \lambda \left( b_u^2 + b_i^2 + \|P_u\|_2^2 + \|Q_i\|_2^2 \right)$$

Where $\lambda$ prevents overfitting on low-frequency items.

### ⚡ Stochastic Gradient Descent (SGD) Updates

For each sample $(u, i, r_{u,i})$, we compute error $e_{u,i} = r_{u,i} - \hat{r}_{u,i}$ and update:
- $b_u \leftarrow b_u + \gamma (e_{u,i} - \lambda b_u)$
- $b_i \leftarrow b_i + \gamma (e_{u,i} - \lambda b_i)$
- $P_u \leftarrow P_u + \gamma (e_{u,i} Q_i - \lambda P_u)$
- $Q_i \leftarrow Q_i + \gamma (e_{u,i} P_u - \lambda Q_i)$

Hyperparameters:
- Factors ($k$): **50**
- Learning Rate ($\gamma$): **0.01**
- Regularization ($\lambda$): **0.02**
- Epochs: **20**

## 🎯 How Recommendations Work

1. **User Validation:** Validates user ID; retrieves continuous 0-indexed ID.
2. **Exclusion Masking:** Gathers all movie indices already rated by the user across both train and test history.
3. **Vectorized Inference:** Fast matrix multiplication predicts ratings across all catalog movies simultaneously:
   $$\hat{R}_u = \text{clip}\left(\mu + b_u + \mathbf{b}_{\text{movies}} + (\mathbf{Q} \cdot P_u), 0.5, 5.0\right)$$
4. **Ranking:** Sorts non-rated candidates in descending order and returns Top-N titles with genre tags and predicted star ratings.

## ⚠️ Known Limitations

1. **Cold-Start Problem:** For completely new users with zero interaction history, collaborative filtering defaults to global mean and item popularity.
2. **Static Embeddings:** SGD in this implementation runs offline batch passes rather than online real-time stream ingestion.
3. **Implicit Feedback:** The model focuses on explicit 0.5–5.0 star ratings rather than implicit signals (clicks, watch-time, dwell-time).

---

## 🔮 Future Improvements

1. **Hybrid Recommender:** Combine matrix factorization with TF-IDF / BERT text embeddings over movie plots and cast lists.
2. **Implicit Feedback Integration:** Implement Bayesian Personalized Ranking (BPR) or Alternating Least Squares (ALS) for click/view logs.
3. **Neural Collaborative Filtering (NCF):** Replace linear dot product with Multi-Layer Perceptron (MLP) towers for non-linear feature interaction.
4. **Fast ANN Vector Search:** Integrate FAISS or ScaNN for sub-millisecond retrieval on million-item catalogs.
